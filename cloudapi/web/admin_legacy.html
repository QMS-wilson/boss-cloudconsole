客户电脑接入步骤（照做即可）

在 D:\v3-wechat 目录放好 Agent 代码（或打包 exe）。
把本页登记的「名称+密钥」填入 v3agent 的 config.json（agent.name / agent.secret）。
服务器地址填云端 wss 地址：wss://你的域名/ws/agent
双击启动（开发机直接运行 py -m v3agent.main --ws）。
回到本页，状态变为「在线」即接入成功。

服务信息

使用帮助

接入第一个本地 Agent：到「本地 Agent」页 → 保存登记（会自动生成密钥）→ 把名称/密钥填进客户电脑的 config.json → 启动 → 本页状态变「在线」。
让小程序能访问：到「客户端令牌」页生成令牌；小程序请求云端时在 Header 带 Authorization: Bearer <令牌>，请求地址 POST /api/v1/rpc。
Agent 一直离线？：先看客户电脑能否访问云端（域名/防火墙），再查 config.json 的 relay_url 与密钥，最后看客户机 logs/agent.out.log。
单据改不了？：Agent 只允许改未审核、无收款/发货/对账/关联的单；已审核单据只读。详见 D:\v3-wechat\README.md。
